# minecraft\_shireker-sensor\_project



This repository includes the following information : 

* Project report
* Project parts list
* The information on main three peripherals used in the project
* Datasheets for all included components if applicable

The project uses the following peripherals of the AtMega328P
* Watchdog // For general reliability 
* TimerOne/Counter 
* A/D Conv // For the microphone/audio sensor
* USART // For the RF transmission

Due to Tampere Univeristy of Applied Sciences information confidentiality rules some documentation will be redacted to not include sensitive information
